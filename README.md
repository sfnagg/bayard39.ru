# bayard39.ru

Сайт ООО «ЧОО «Баярд» — частной охранной организации в Калининграде.

Статический HTML без сборки: правите файл — правится страница. Хостинг GitHub Pages,
деплой автоматический при мерже в `main`, домен из `CNAME`.

`.htaccess` в репозитории мёртвый — он остался от прежнего хостинга, на GitHub Pages
правила Apache не работают. Редиректы делать через него нельзя.

### Переобход после правок

```bash
python tools/pereobhod.py                      # страница вакансий
python tools/pereobhod.py https://www.bayard39.ru/   # любые адреса
```

В Яндекс уходит любой адрес, суточная квота около 150. В Google — только страница
вакансий: Indexing API принимает `JobPosting` и `BroadcastEvent`, остальные страницы
там по-прежнему отправляются вручную через «Проверка URL» в Search Console.

Ключи лежат вне репозитория, в каталоге `.secrets` домашней папки: токен Яндекса
действует полгода, ключ сервисного аккаунта Google — бессрочно. Сервисный аккаунт
добавлен в Search Console **владельцем**; «Полный доступ» не подходит, API отвечает 403.

Сводка Вебмастера отстаёт от выборки на несколько дней — смотреть `in-search/samples`,
а не цифры в сводке. Google догоняет медленнее Яндекса.
